### Tutorial and model of the leech heartbeat timing network (Release 8/20/99)

This new tutorial includes introductory material, a graphical user interface to the model, and suggested experiments to help the user explore and understand the model.

You'll need three things to run the network leech model:
1) the GENESIS simulation program,
2) the GENESIS script files for the model and tutorial, and
3) an extension to GENESIS that is required by our GENESIS files.

Items 2 and 3 are available at this site, and you can get GENESIS at [http://www.genesis-sim.org/GENESIS/](http://www.genesis-sim.org/GENESIS/). Instructions for running the model are contained in item 2.

1. [The GENESIS simulation program](http://www.genesis-sim.org/GENESIS/)
2. Extensions to GENESIS required by the model of Heart Interneuron Network:
    - [Leech Heart Interneuron Libraries (Genesis Objects)](http://senselab.med.yale.edu/modeldb/data/112348/leech-libraries.tar)
    - [Tutorial on Genesis of Leech HeartBeat and Leech Interneuron Libraries](http://senselab.med.yale.edu/modeldb/data/112348/tutorial.tar)
    - [No luxury graphics version of the Network](http://senselab.med.yale.edu/modeldb/data/112348/HN-NET.TAR)

Use `tar -xvf filename.tar` to extract files from the tar archives above.
